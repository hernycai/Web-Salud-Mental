# 🧠 Portal de Salud Mental | Argentina & Global

> **Plataforma integral de divulgación científica, guías clínicas basadas en evidencia, historia de las disciplinas "psi" y espacio comunitario de testimonios.**

---

## 🌟 Descripción General

El **Portal de Salud Mental** es una aplicación web interactiva de acceso libre diseñada para democratizar el conocimiento sobre la salud mental con el más alto rigor científico, empatía y accesibilidad universal. 

Combina investigación académica y clínica fundamentada en los estándares internacionales (**DSM-5-TR**, **CIE-11** y directrices **QualityRights de la OMS**) con recursos prácticos de asistencia en crisis, psicoeducación para pacientes y familiares, y un espacio seguro para relatos en primera persona.

| **04** | **Trastornos de Ansiedad & Manejo de Pánico** | *Trastornos Clínicos* | Diferencia entre miedo y ansiedad, eje intestino-cerebro, fármacos de primera línea (ISRS/IRSN), TCC y protocolo paso a paso de auxilio en crisis de pánico (técnica 4-4-4). |
| **05** | **Estado Actual de la Depresión** | *Trastornos Clínicos* | Caracterización de la Depresión Atípica (parálisis plúmbea, reactividad del ánimo), factores protectores de las redes de apoyo e innovaciones (Esketamina nasal, Brexanolona). |
| **06** | **Intervención en Estrés Postraumático (TEPT y C-TEPT)** | *Trastornos Clínicos* | Neurobiología de la memoria traumática (amígdala e hipocampo), TEPT Complejo y protocolo de Terapia Combinada (*Terapia Metacognitiva* + *Exposición Prolongada*). |
| **07** | **Neurobiología y Estrategias en el TDAH** | *Trastornos Clínicos* | Circuitos frontoestriatales y dopamina, evidencia del estudio MTA del NIMH (68% de éxito en tratamiento combinado) y pautas de crianza estructurada con refuerzo positivo. |
| **08** | **Trastorno de la Conducta Disocial** | *Trastornos Clínicos* | Criterios CIE-11 (persistencia de 12 meses), especificador de emociones prosociales limitadas, genética y programas de entrenamiento para padres avalados por *NICE*. |
| **09** | **Mitos y Realidades del Trastorno Bipolar** | *Trastornos Clínicos* | Genética (*ANK3* y *BDNF*), fenotipado digital con smartphones para anticipar recaídas maníacas, estabilidad circadiana y el rol antisuicida fundamental del Carbonato de Litio. |
| **10** | **Avances en Psicosis y Esquizofrenia** | *Trastornos Clínicos* | Descubrimiento del gen *C4* de poda sináptica (Harvard), fármaco agonista muscarínico *COBENFY* (sin bloqueo D2), TCCp con el modelo de las *3 C* y rehabilitación psicosocial. |
| **11** | **Accesibilidad Sanitaria en el Espectro del Autismo (TEA)** | *Trastornos Clínicos* | Detección precoz (<3 años), unidades hospitalarias integrales (*AMI-TEA*), tarjeta sanitaria preferente (*AA*) y accesibilidad cognitiva mediante pictogramas y agendas visuales. |
| **12** | **Trastornos de la Conducta Alimentaria (TCA)** | *Trastornos Clínicos* | Anorexia nerviosa, bulimia, atracón, variantes emergentes (*Anorexia Atípica*, *Diabulimia*, *ARFID*), ensayos clínicos *MOSAIC/SWAN* (*MANTRA*, *CBT-E*) y directrices APA 2023. |
| **13** | **Discapacidad Intelectual y Adicciones** | *Trastornos Clínicos* | Patología dual, fenómeno del *Enmascaramiento Diagnóstico* (*Diagnostic Overshadowing*), prevención somática de *The Fatal Five* y programa adaptado *Take It Personal!+*. |

### 2. 🆘 Red de Asistencia Inmediata y Líneas de Crisis 24hs
- **Modal de Emergencias Interactivo**: Acceso rápido con un solo clic a números gratuitos, confidenciales y oficiales de intervención en crisis:
  - **Argentina**: Línea 135 (Centro de Asistencia al Suicida), 0800-999-0091 (Salud Mental Nacional), Salud Mental Responde (CABA) y Línea 141 (Sedronar).
  - **Internacional**: Líneas de crisis para España (024 / 717 003 717), México (Línea de la Vida 800 911 2000), Colombia (106), Chile (*4141), Uruguay (0800 0767) y Estados Unidos (988).

### 3. 💬 Board Comunitario de Testimonios Anónimos
- Espacio respetuoso y seguro para leer y compartir relatos de recuperación en primera persona y vivencias de familiares/cuidadores.
- **Filtros por categoría**: Ansiedad, Depresión, TDAH, Bipolaridad, Trauma, etc.
- **Formulario interactivo**: Permite enviar experiencias garantizando el anonimato y la seguridad comunitaria.

### 4. 🔍 Búsqueda y Filtros Dinámicos
- Búsqueda instantánea en tiempo real por palabra clave, síntomas, autores o número de guía.
- Filtros rápidos por categoría temática (*Historia Global*, *Historia Argentina*, *Epidemiología*, *Trastornos Clínicos*).

## 🚀 Instalación y Ejecución Local

### Prerrequisitos
- **Node.js** (versión 18.0 o superior recomendada)
- **npm** (versión 9.0 o superior)

### Pasos

1. **Clonar o descargar el repositorio:**
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   cd Portal-de-Salud-Mental
   ```

2. **Instalar las dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   La aplicación se abrirá en `http://localhost:3000` (o el puerto indicado en la consola).

4. **Verificar tipos y linter:**
   ```bash
   npm run lint
   ```

5. **Compilar para producción:**
   ```bash
   npm run build
   ```
   Los archivos optimizados se generarán en la carpeta `dist/`.
